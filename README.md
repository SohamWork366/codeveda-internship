# CodeVeda Internship

This repository contains the projects and tasks I completed during my CodeVeda internship.

## Projects

### Beginner

* **Guessing Game** — A Python number guessing game.
* **Calculator** — A simple calculator program implemented in Python.

### Intermediate

* **To-Do List** — A task management application that stores tasks using JSON.
* **Weather App** — A Python application that retrieves weather information using an API.

### Advanced

* **File Encryption** — A Python program for encrypting and decrypting files.
* **N-Queens** — A Python implementation of the N-Queens problem.
